# Mi Dashboard de Proyectos

Este es tu espacio personal para guardar el historial de todos tus proyectos
y lo que vas aprendiendo, para no tener que explicármelo otra vez cada vez
que hablemos.

No necesitas abrir ni editar nada de esto a mano — yo (Claude) lo leo y lo
actualizo automáticamente durante nuestras conversaciones. Esta página es
solo para que entiendas qué hay guardado y dónde, por si alguna vez quieres
echar un vistazo.

## Cómo está organizado

- **`DASHBOARD.md`** — la vista general: una tabla con todos tus proyectos,
  su estado (activo, pausado, terminado) y un resumen corto de cada uno.
- **`proyectos/`** — una carpeta con un archivo por proyecto, con más
  detalle: qué es, decisiones importantes que tomamos, y lecciones
  aprendidas específicas de ese proyecto.
- **`memoria/preferencias.md`** — cómo te gusta trabajar (por ejemplo: que
  no sabes programar, que prefieres explicaciones simples, en español,
  etc.). Esto me ayuda a no volver a preguntarte lo mismo.
- **`memoria/lecciones-generales.md`** — aprendizajes o errores que no son de
  un solo proyecto, sino que aplican a varios.

## Cómo se usa

Simplemente háblame como siempre. Cuando mencionemos un proyecto nuevo, lo
registro aquí. Cuando tomemos una decisión importante o resolvamos un
problema, lo anoto para el futuro. No tienes que hacer nada extra.
